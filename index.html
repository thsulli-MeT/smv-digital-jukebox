sMV Playlist Jukebox

This version drops the big hand-built video catalog and runs directly from YouTube playlist links. Paste an sMV playlist URL, save it as a station, and the jukebox loads the playlist straight into the YouTube player.

No catalog JSON requiredThe player loads YouTube playlist IDs directly instead of maintaining a custom database of every track.
Built around playlistsEach saved station points at an sMV playlist, so the channel can keep curating in YouTube.
Lightweight workflowTo add music later, just copy a playlist link from the sMV playlists page and save it here.

This lets the jukebox stay simple: YouTube handles playlist ordering, while this app only stores a small list of saved stations in your browser.
  • Use the Open sMV playlists button to browse the channel and copy a playlist link.
  • When you save a station, it is stored in localStorage so the setup stays lightweight.
  • The YouTube playlist remains the single source of truth, so new videos can be added on YouTube without rebuilding a JSON catalog.
